## 2. Optimizations (applied)
- `RuntimeMonitorService`: contracts loaded once per poll (was `findAll()` per block); no block downloads while nothing is registered.
- `RiskFusionService`: identical score/band within 30 s no longer writes a new assessment + factor rows per active block.
- Registry duplicate-address check is a SQL `exists`, Overview alert count is a SQL `count`.
- `SystemStatusService`: analyzer health cached 10 s (was a blocking probe per Overview load).
- JWT secret validated at startup (>= 32 bytes) with a clear message.
- Frontend: deleted dead mock layers (`api/client.js`, `analysisEngine.js`, `mockData.js`, `data/mockSecurityData.js`) that `FIXES.md` said were gone; build passes (**Verified**).
- `.gitignore` rewritten (it had markdown fences and a bogus `**/!.env.example`); `.gitattributes` added (mixed CRLF/LF).
